COIN TAP — IMPORT FIXTURE v1.0

Open index.html directly, or import this folder into Jabali Studio as a Web Game.
Click the coin five times to win. Restart resets the score and coin position.
The same button supports touch and keyboard Enter/Space.

No package installation, server, build, CDN, fetch requests, or network needed.
Files: index.html, styles.css, game.js, assets/coin.svg, README.txt.
The external stylesheet, script, and nested SVG make missing copied files visible.
